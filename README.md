# Homebrew tap

Install `jira-ops`:

```bash
brew install amaljithkuttamath/tap/jira-ops
```

Upgrade it after a new release:

```bash
brew upgrade jira-ops
```

For commands, authentication, and release verification, see
[`jira-ops`](https://github.com/amaljithkuttamath/jira-ops).

This tap also contains [`crux`](https://github.com/amaljithkuttamath/crux):

```bash
brew install amaljithkuttamath/tap/crux
```
